# ADR-003: 自研可增量维护的 BM25，不使用第三方实现

## Status

Accepted (2026-09-22)

## Background

主流 BM25 库（如 rank-bm25）要求一次性传入完整语料来构造 `BM25Okapi`。
知识库是动态增长的，每摄入一篇文档就重建一次索引，在 n 篇文档的过程中总复杂度是 O(n²)，
而且重建期间索引不可用。

## Decision

自研 `IncrementalBM25`，维护三组增量统计：词频表 `tf`、文档频率 `df`、文档长度 `len`，
支持单条 `add` / `delete`；检索时按需计算分数。
IDF 使用平滑式 `ln(1 + (N - df + 0.5)/(df + 0.5))`。

## Consequences

正面：
- 动态知识库下单条增删是 O(文档词数)，无需重建
- 少一个外部依赖，行为完全可控、可测试
- 删除文档时 df 同步下降，避免 IDF 漂移

负面：
- 检索是 O(语料规模 × 查询词数)，没有倒排索引加速；当前体量下远低于毫秒级影响上限
- 后续如果语料上到百万级，需要改为倒排 + WAND 剪枝
