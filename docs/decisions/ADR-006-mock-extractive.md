# ADR-006: 内置抽取式 Mock 模型，保证离线端到端可验证

## Status

Accepted (2026-09-22)

## Background

常见做法是把模型调用替换成一个返回固定字符串的 stub。这样一来，
Mock 模式下「检索到的资料有没有被真正使用」就永远无法验证 ——
流水线里任何一处断链都会被伪装成正常。

## Decision

`MockLLM` 实现**抽取式生成**：解析 prompt 中形如 `[来源 k] text` 的上下文块，
按与问题的词汇重叠度选出最相关的一条，拼出答案并在末尾附上来源编号。

因此即使在 Mock 模式下：
- 「答案里出现了正确片段」是可断言的
- 「引用映射到了正确的分片」是可断言的
- 「检索结果被真正喂给了模型」是可断言的

同时在生产链路里，`LLMRouter` 把 mock 作为兜底 provider，
主模型不可用时自动降级并在答案前标记 `[模型降级]`。

## Consequences

正面：
- 无网络、无 Key、无 GPU 的 CI 环境里，端到端链路仍然真实运行
- 降级行为本身也可以被测试覆盖
- Mock 行为确定，测试不会随机失败

负面：
- Mock 不是真正的语言理解，无法评估生成质量（这需要真实模型 + 裁判）
