# ADR-002: 混合检索使用 RRF 融合而非加权求和

## Status

Accepted (2026-09-22)

## Background

要把 BM25（稀疏）与向量（稠密）两路结果合并，直觉做法是加权求和。
但 BM25 分数没有上界，余弦相似度被限制在 [-1,1]，两者量纲完全不同。
必须归一化才能相加，而归一化所需的极值会随语料不断变化 ——
同一套权重在这个知识库表现良好，换个知识库就失真。

## Decision

采用倒数排名融合（Reciprocal Rank Fusion），只使用名次信息：

```
rrf_score(d) = Σ_r 1 / (k + rank_r(d))     k = 60
```

并把候选宽度设为最终数量的 4 倍，避免「在两路都排在第 15 名」的正确答案在融合阶段被丢弃。

## Consequences

正面：
- 天然免疫量纲差异，换语料、换嵌入模型后不需要重新调权重
- 实现简单，行为可预测，易于写测试（有明确的数学不变量）

负面：
- 丢弃了原始分数的大小信息，两路都「勉强命中」与「强命中」不再区分
- k 值仍是经验值（60），极端场景可能需调整
